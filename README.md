# Prometeu 🔥

## Introdução

Prometeu é uma plataforma de inclusão digital criada para facilitar o acesso ao conhecimento disponível gratuitamente na internet. O projeto reúne, organiza e apresenta recursos educativos com curadoria, ajudando qualquer pessoa a encontrar caminhos de aprendizagem confiáveis sem precisar perder tempo em buscas dispersas.

## Inspiração

O nome Prometeu é inspirado no mito de Prometeu, personagem da mitologia grega que entregou o fogo à humanidade. A chama representa o conhecimento, a evolução e a capacidade humana de transformar a própria realidade. Da mesma forma, o projeto busca manter essa chama viva por meio do acesso democrático ao conhecimento digital.

## Problema que o projeto resolve

Embora exista uma enorme quantidade de conteúdo gratuito online, muitas pessoas enfrentam dificuldades para encontrar materiais confiáveis, identificar plataformas de qualidade e descobrir quais recursos oferecem certificação válida. O Prometeu resolve esse problema ao ser um hub de curadoria que transforma dispersão em descoberta estruturada.

## Objetivos

- Promover inclusão digital por meio de descoberta simplificada.
- Reduzir a barreira de acesso a recursos educacionais gratuitos.
- Oferecer um ambiente confiável para quem tem pouco familiaridade com plataformas digitais.
- Conectar usuários a conteúdos relevantes para estudo, trabalho e desenvolvimento de habilidades.

## Funcionalidades

- Catálogo de ferramentas e plataformas gratuitas.
- Organização de recursos por categorias.
- Filtros para facilitar a descoberta de conteúdos.
- Guia de plataformas que oferecem certificados oficiais.
- Curadoria de links confiáveis.
- Informações detalhadas sobre cada recurso e sua finalidade.
- Navegação simples e acessível.

## Estrutura do projeto

A estrutura do Prometeu foi pensada para suportar uma navegação clara e escalável, com separação entre curadoria de conteúdo, apresentação de recursos e filtros de pesquisa.

- /src: código-fonte da interface e lógica de apresentação.
- /public: ativos estáticos e imagens.
- /data: lista de recursos, categorias e metadados.
- /components: componentes reutilizáveis para cards, filtros e guias.
- /docs: documentação complementar e diretrizes de curadoria.

> Ajuste esta estrutura conforme a organização real do projeto.

## Tecnologias utilizadas

* **React 19** — Biblioteca principal para a construção da interface do usuário.
* **Vite** — Build tool ultra-rápido para o desenvolvimento do ecossistema front-end.
* **TypeScript** — Tipagem estática para garantir um código seguro e livre de bugs.
* **TanStack Ecosystem** — Configuração nativa via Lovable para gerenciamento de rotas ou dados de alta performance.
* **Nitro** — Motor de servidor embutido de altíssima velocidade para otimização de performance.
* **Tailwind CSS** — Framework utilitário de CSS para estilização rápida, moderna e responsiva.
* **Lucide React** — Biblioteca de ícones minimalistas e otimizados para a interface.

## Como executar localmente

1. Clone este repositório:
   ```bash
   git clone https://github.com/Nicolinux-dev/Prometeu
   ```
2. Entre na pasta do projeto:
   ```bash
   cd Prometeu
   ```
3. Instale as dependências:
   ```bash
   npm install
   ```
4. Inicie a aplicação em modo de desenvolvimento:
   ```bash
   npm run dev
   ```
5. Abra o navegador em `http://localhost:3000` (ou conforme configurado).

> Atualize os comandos acima de acordo com o gerenciador de pacotes e as ferramentas usadas no projeto.
